## Working rules
- Before any completion claim: tests pass **and** a real browser smoke check.
- Edge deploys use exactly the files in `MANIFEST.json`, from this repo. After deploying, fetch `GET /health` and run
  `node scripts/check-edge.mjs --live '<json>'`. For a byte-for-byte check, also compare the deployed files with this repo.
- After any database migration for the app, run `select delivery_app_selfcheck();` (privileges, trigger, table exposure).
- No real business data in commits, fixtures or this file.

## Changes on 26 Nov 2026 (technical outcomes)
- Shelf price list (read-only, cached Square copy refreshed on open); recent deliveries list (14 days in full, months folded).
- Booked-flag repair on invoice lines plus a fail-closed trigger (`trg_invoice_line_mark_booked`).
- Security: app RPCs are no longer callable by `anon`/`authenticated`; service role only.
- UI fixes: context-safe onclick arguments (`ja()`), stale-async guards (`VIEW` token), separate owner slots,
  month-load error and stale-reply handling, authoritative booked/waiting counts.
- Auth (v15): config read errors or empty values raise `ConfigUnavailable` -> **503** (never cached, never shown as
  "device not set up"); malformed/wrong keys stay **401**; concurrent reads share one request. The page shows a retry
  banner on 503. Routes that previously turned database errors into empty success now return errors.
- Deploy guard: structural checks (no placeholder), embedded `SOURCE_SHA`, `MANIFEST.json`, live `/health` comparison.
  Deployed Edge version 16 = build "delivery-app v15 2026-11-26"; live `/health` matched this source.
